# تبدیل پروژه به رشد — ۲۰ عقرب ۱۴۰۵ / 2026-11-11

- هویت برنامه، namespace اندروید و JNI، تنظیمات، پایگاه داده و کلیدهای محلی به رشد تغییر کردند.
- آدرس اصلی API، ورود، فایل‌ها و میزبان مجاز به‌روزرسانی: `https://roshd.azmoonic.com`.
- لوگوی رسمی از `/roshd-symbol.png` همان سایت دریافت شد و در تمام آیکن‌ها، صفحهٔ آغاز و سربرگ‌های هر دو تم قرار گرفت.
- بخش حاضری، اسکن کارت، ثبت و ارسال، تلاش مجدد، فیلتر شاگردان بر اساس حاضری، گزارش مدیر، مهاجرت صف قدیمی، صدای مخصوص و ترجمه‌های مربوط حذف شدند.
- میان‌برهای حذف‌شده با آرشیف و نتیجه‌ها جایگزین شدند. فهرست شاگردان نام و شناسه را نشان می‌دهد. صف فقط پاسخ‌نامه می‌پذیرد.
- انتخاب دور، گزارش‌ها و اطلاع‌نامه‌ها از دورهای ۱ تا ۱۲ پشتیبانی می‌کنند.
- موتورهای اسکن و وابستگی‌های اصلی بازنویسی نشده‌اند. نام پروژهٔ CMake و متن معرفی تغییر کرده‌اند؛ bridge JNI با namespace تازه هماهنگ است.
- خروجی‌ها، عکس‌ها و مستندات تاریخی پروژهٔ قبلی به پوشهٔ پشتیبان خارج از پروژه منتقل شدند: `../.codex-backups/roshd-before-2026-11-11`.

بررسی زندهٔ سایت: عنوان «امتحان جامع رشد» و لوگوی عمومی دریافت شدند. مسیر `/api/v1/scanner/configuration` پاسخ 401 با پیام نیاز به ورود اسکنر داد. مسیر بررسی نسخه در زمان بررسی پاسخ 503 داد؛ این وضعیت سمت سرور است. ورود واقعی، دریافت بستهٔ امضاشده و ارسال به حساب رشد بدون حساب معتبر آزموده نشده‌اند. این وضعیت مربوط به نسخهٔ 1.1.13 است. در نسخهٔ 1.1.14 نام قراردادهای شبکه و امضاها با راهنمای API رشد تطبیق داده شدند؛ [گزارش نسخهٔ تازه](FOLDERS_AND_API_1.1.14.md).
