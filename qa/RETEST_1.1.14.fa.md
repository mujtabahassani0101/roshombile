# آزمایش دوبارهٔ رشد 1.1.14

این گزارش مربوط به بررسی اولیهٔ بدون حساب است. آزمایش بعدی با حساب ارسالی، شامل ورود و دریافت bundle دور ۱، در [تست حساب واقعی](AUTHENTICATED_TEST_1.1.14.fa.md) ثبت شده است.

زمان اجرای نهایی: ۱۱ نوامبر ۲۰۲۶، حدود ساعت ۱۸:۳۵ UTC / ۲۳:۰۵ کابل.

| بررسی | نتیجه |
| --- | --- |
| آزمون‌های محلی JVM | ۸۸ موفق؛ صفر شکست |
| نگاشت QR بومی C++ روی میزبان | ۸ بررسی موفق |
| ابزارهای بررسی و بسته‌بندی | ۱۰ آزمون موفق |
| آزمون زنده با HTTP client خود اپ | ۶ آزمون؛ ۵ موفق، ۱ ناسازگاری سرور |
| امضای APK، ZIP و کتابخانهٔ ARM64 | موفق |
| سه تصویر OMR داخل APK | هر سه سالم، ۴۲۰×۵۹۵، دقیقاً مطابق سورس |
| تصویر قدیمی کتاب/مداد، نام قدیمی و قرارداد قدیمی شبکه در DEX | پیدا نشد |
| اجرای شبیه‌ساز | انجام نشد |
| اجرای رابط روی گوشی واقعی | انجام نشد؛ گوشی واقعی متصل نبود |

آزمون‌های زنده، `ConnectionsManager` و `AppRelease.parse` واقعی برنامه را در JVM اجرا کردند؛ این بررسی معادل اجرای رابط، دوربین یا TLS اندروید روی دستگاه نیست. همهٔ درخواست‌ها GET بودند و حساب یا داده‌ای در سرور ایجاد یا تغییر نکردند.

| درخواست | انتظار | پاسخ واقعی |
| --- | --- | --- |
| `/api/v1/mobile/app-version?platform=android&versionCode=4200` | ۲۰۰ و قرارداد رشد قابل‌خواندن توسط اپ | موفق؛ `roshd.mobile-app-version.v1`، آخرین انتشار null |
| `/api/v1/scanner/configuration` بدون ورود | ۴۰۱ | موفق؛ `authentication_required` |
| configuration با bearer ساختگیِ نامعتبر | ۴۰۱ | موفق؛ `authentication_required` |
| receipt با شناسه‌های ثابت آزمایشی و بدون ورود | ۴۰۱ | موفق؛ `authentication_required` |
| `/api/v1/school-manager/portal` بدون ورود | ۴۰۱ | موفق؛ ProblemDetails بدون فیلد code، اپ آن را `http_401` نگه داشت |
| `/api/v1/mobile/app-version?platform=android` بدون `versionCode` | ۴۰۰ طبق راهنمای API | **ناموفق؛ ۵۰۳، `unavailable`، عنوان `App release storage temporarily unavailable`** |

ناسازگاری درخواست آخر در سه بررسی جداگانه تکرار شد، از جمله یک درخواست مستقل Python. پاسخ `Retry-After: 5` داشت. بررسی نسخهٔ عادی اپ همیشه `BuildConfig.VERSION_CODE` را می‌فرستد و در همین آزمایش ۲۰۰ گرفت. علت داخلیِ خطای ۵۰۳ بدون بررسی لاگ سرور مشخص نیست؛ این گزارش آن را موفق قلمداد نمی‌کند.

ورود با حساب واقعی، دریافت بستهٔ امضاشده، ارسال پاسخ‌نامه، آپلود عکس، دریافت اطلاع‌نامه و خواندن عکس با موتور OMR روی گوشی هنوز آزمایش نشده‌اند. حساب معتبر در اختیار این آزمایش نبود. پیش‌نمایش پوشه‌ها بازبینی شد؛ تصویر موجود رندر ثابت است و اسکرین‌شات اجرای برنامه نیست.

گزارش‌ها:

- `retest-1.1.14-jvm.log`: اجرای دوبارهٔ آزمون‌های محلی پیش از افزودن تست زنده؛ موفق.
- `retest-1.1.14-final.log` و `retest-1.1.14-jvm-summary.json`: اجرای نهایی ۹۴ آزمون، ۹۳ موفق و یک شکستِ ذکرشده در بالا.
- `retest-1.1.14-live-final.xml`: نتیجه و خروجی شش آزمون زنده.
- `retest-1.1.14-live-http.json`: تأیید مستقل HTTP، بدون هویت.
- `retest-1.1.14-native.log`، `retest-1.1.14-tools.log`، `retest-1.1.14-apk.json` و `retest-1.1.14-apk-signature.log`.

تست زنده با متغیر زیر فعال می‌شود؛ در اجرای معمولی، شش تست زنده skip می‌شوند و اینترنت لازم ندارند:

```sh
ROSHD_LIVE_API_TEST=1 ./gradlew :app:testDebugUnitTest --rerun --no-daemon --max-workers=1 -Dorg.gradle.jvmargs='-Xmx768m -Dfile.encoding=UTF-8' -Pkotlin.compiler.execution.strategy=in-process --console=plain
```

در وضعیت فعلی سرور، دستور بالا به‌دلیل همان پاسخ ۵۰۳ با exit code یک تمام می‌شود. شرط تست به ۵۰۳ تغییر داده نشده است.
