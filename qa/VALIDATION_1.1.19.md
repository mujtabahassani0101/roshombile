# اصلاح بسته‌شدن هنگام بازکردن — رشد 1.1.19 / 4205

کاربر بسته‌شدن فوری هنگام بازکردن برنامه را گزارش کرد. گوشی متصل نبود؛ شبیه‌ساز طبق خواست کاربر اجرا نشد. یک خطای مشخص در همان مسیر شروع پیدا و با اجرای کد Android روی JVM بازتولید شد.

## علت و اصلاح

پس از حذف خانوادهٔ ۶۰سؤاله، پیش‌نمایش تم در `ThemePicker.kt` همچنان نام تصاویر سه خانواده را از شمارهٔ حلقه تولید می‌کرد. برای تصویر دوم، `StudyArt` مسیر ناموجود `images/study-omr-t2.png` را باز می‌کرد. `FileNotFoundException` از `ThemePreviewView.onDraw` خارج می‌شد؛ این نما در انتخاب تمِ آغاز و تنظیمات استفاده می‌شود.

اکنون پیش‌نمایش، دو تصویر موجود ۴۰ و ۱۰۰سؤاله را یک بار بارگذاری و در سه پوشهٔ تزئینی تکرار می‌کند. نام خانواده از شمارهٔ پوشه ساخته نمی‌شود. تصویر یا موتور ۶۰سؤاله برگردانده نشده است. قالب‌ها، منطق اسکن و رنگ‌گذاری، پایگاه داده، کلیدها و حساب تغییری نکرده‌اند.

## بررسی

- آزمون قبل از اصلاح: رسم واقعی `ThemePreviewView` در Robolectric / Android API 28 با همان `FileNotFoundException` شکست خورد. [گزارش خطای بازتولیدشده](crash-before-fix-1.1.18.xml).
- بعد از اصلاح: هر چهار آزمون Android روی JVM و API 28 با حافظهٔ آزمایشی تازه و بدون حساب موفق شدند؛ رسم پیش‌نمایش، راه‌اندازی و چرخهٔ فعالیت Study، راه‌اندازی و چرخهٔ فعالیت Organic و ساخت/جایگزینی/پاک‌کردن عکس در نمای بزرگ‌نمایی. [گزارش بعد از اصلاح](crash-after-fix-1.1.19.xml).
- تمام تست‌های برنامه: ۱۶۲ موفق، صفر شکست؛ ۷ تست زنده skip. [خلاصه](unit-tests-1.1.19.json).
- تست‌های چرخهٔ فعالیت با JDK 21 اجرا می‌شوند، چون کتابخانهٔ موجود Backdrop کلاس Java 21 دارد؛ هدف بایت‌کد Android همچنان Java 17 است. خطای اولیهٔ JVM 17 مربوط به محیط تست بود و با انتخاب launcher صحیح رفع شد.
- Android Lint: صفر خطا و ۹۶ هشدار. کد آزمون دستگاه کامپایل شده است؛ اجرای روی دستگاه فیزیکی یا شبیه‌ساز انجام نشده است.
- نسخهٔ جدید با همان شناسهٔ برنامه و گواهی نسخهٔ 1.1.18 بسته‌بندی می‌شود؛ به‌روزرسانی، اطلاعات ذخیره‌شده را حفظ می‌کند.

نتیجهٔ نهایی ساخت و lint در `build-1.1.19-final.log`، ممیزی APK در `apk-audit-1.1.19.json` و امضا و نسخه در `apk-signature-1.1.19.log` و `apk-badging-1.1.19.log` ثبت شده‌اند. فایل‌ها و SHA-256 در [فهرست خروجی](../output/roshd-1.1.19-artifacts.json) هستند.

این رگرسیون با اجرای مسیر خطادار روی JVM تأیید شده است؛ بدون لاگ گوشی نمی‌توان همهٔ علت‌های احتمالی بسته‌شدن روی یک دستگاه خاص را رد کرد. [گزارش قابلیت برگهٔ رنگی](VALIDATION_1.1.18.md).
