# Feather image icon

The original SVG is vendored unchanged from Feather v4.29.2:
https://github.com/feathericons/feather/blob/v4.29.2/icons/image.svg

Copyright Cole Bemis, MIT; the original LICENSE is included.
No vector geometry was redrawn. The archive export changes only stroke color
and width to match the reference's 80-pixel outline with a 2-pixel stroke.
`tools/render_archive_icon.cjs` renders a transparent 3× bitmap from this
library icon; The native app does not require an additional SVG runtime dependency.
